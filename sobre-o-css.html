Tags HTML Utilizadas no Projeto

  • <header>, <nav>, <main>, <section>, <aside>, <footer>: Tags semânticas utilizadas para estruturar as diferentes secções de cada página.
  • <h1>, <h2>: Títulos e subtítulos organizados hierarquicamente.
  • <p>: Parágrafos para a apresentação de textos e descrições.
  • <ul>, <li>: Listas não ordenadas utilizadas nos menus, índices e explicações.
  • <a>, <button>: Hiperligações de navegação interna/externa e botões interativos.
  • <figure>, <img>, <figcaption>: Agrupamento de imagens com as respetivas legendas.
  • <input>, <label>: Utilizados para criar o menu hambúrguer interativo (Menu Toggle via CSS).
  • <strong>, <sup>: Destaque de texto em negrito e texto sobrescrito (ex: 1o campeonato).
  • <div>: Contentores genéricos para organização de blocos e layouts.
  • <hr>, <br>: Linhas de separação visual e quebras de linha.

Propriedades CSS Utilizadas no Projeto

  • display: flex: Ativa o modelo Flexbox para alinhar e distribuir elementos na página.
  • flex-direction: Define a direção dos itens no Flexbox (em coluna column para telemóveis e em linha row para ecrãs maiores).
  • justify-content: Alinha os elementos no eixo principal (ex: center, flex-start, space-between).
  • align-items: Controla o alinhamento dos itens no eixo secundário (ex: center, flex-start).
  • flex-wrap: Permite que os elementos quebrem para a linha seguinte quando não couberem no ecrã.
  • gap: Define o espaçamento entre elementos dentro de um contentor Flexbox.
  • width, max-width, height: Ajustam a largura e altura de caixas e imagens, garantindo a responsividade.
  • margin, padding: Controlam as margens externas e o espaçamento interno dos elementos.
  • border-radius: Arredonda as bordas de imagens e caixas do site.
  • background-color, color: Definem as cores de fundo e do texto.
  • :hover: Pseudoclasse utilizada para aplicar efeitos visuais ao passar o cursor sobre botões e links.
  • @media (min-width: ...): Regras de responsividade para adaptar o layout a computadores e tablets.
