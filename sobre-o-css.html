Novas Tags HTML Explicadas

  • <aside>
    Funcionalidade: Define um bloco de conteúdo que está tangencialmente relacionado com o conteúdo principal à sua volta (como barras laterais ou menus de índice).
    Por que foi usado: Foi utilizado na página temática para encapsular o índice "Navegue pelos blocos", separando-o semanticamente dos tópicos principais.
  • <input>
    Funcionalidade: Cria um controlo interativo para formulários ou para guardar estados (neste caso, o estado de uma caixa de verificação / checkbox).
    Por que foi usado: Utilizado (com type="checkbox") para controlar a abertura e o fecho do menu hambúrguer em dispositivos móveis, sem necessitar de JavaScript.
  • <label>
    Funcionalidade: Representa uma legenda ou rótulo associado a um elemento de interface de utilizador (como um input).
    Por que foi usado: Utilizado para criar o ícone do menu hambúrguer (☰). Ao ser associado ao <input> através da propriedade for, clicar no label ativa/desativa o checkbox oculto.
  • <details>
    Funcionalidade: Cria um widget de expansão a partir do qual o utilizador pode exibir ou ocultar informações adicionais.
    Por que foi usado: Permite criar secções de conteúdo expansível para organizar blocos grandes de texto sem sobrecarregar a página visualmente.
  • <summary>
    Funcionalidade: Define um cabeçalho visível para o elemento <details>.
    Por que foi usado: Serve como o título clicável que o utilizador pressiona para abrir ou fechar o conteúdo oculto dentro da tag details.
  • <blockquote>
    Funcionalidade: Indica que o texto incluído é uma citação longa retirada de outra fonte.
    Por que foi usado: Aplicado para destacar blocos de texto inspiracionais ou frases importantes em seções do projeto.
  • <cite>
    Funcionalidade: Representa a referemcia ou o título de uma obra
    Por que foi usado: Usado dentro ou próximo dos blockquotes para dar credito ao autor ou a origem da citação.

Novas Propriedades CSS Explicadas

  • flex-wrap
    Funcionalidade: Define se os elementos num contentor Flexbox devem tentar encaixar-se numa única linha ou quebrar para múltiplas linhas se não houver espaço.
    Por que foi usado: Utilizado para permitir que as imagens da galeria (na página do sonho) se reorganizem automaticamente para baixo quando exibir em uma tela menor.
  • gap
    Funcionalidade: Controla o espaçamento vazio entre linhas e colunas dentro de um layout Flexbox ou CSS Grid.
    Por que foi usado: Substitui o uso complexo de margens, garantindo um espaçamento uniforme entre os botões do menu, ou entre o menu lateral e o conteúdo na página temática.
  • text-decoration
    Funcionalidade: Especifica decorações visuais adicionadas ao texto, como sublinhados.
    Por que foi usado: foi configurado como none para remover o sublinhado dos links (tags <a>), tornando o design mais limpo.
  • font-weight
    Funcionalidade: Define a espessura dos caracteres do tipo de letra.
    Por que foi usado: Utilizado para destacar partes de texto importantes, aplicando negrito (ex: bold) nos títulos e chamadas para ação.
  • box-shadow
    Funcionalidade: Adiciona efeitos de sombra em redor da caixa de um elemento.
    Por que foi usado: Utilizado para dar uma sensação de profundidade e destaque em componentes como o menu lateral ou botões flutuantes.
  • box-sizing
    Funcionalidade: Define como o navegador calcula a largura e a altura totais de um elemento.
    Por que foi usado: Configurado como border-box para assegurar que a margem interna (padding) não aumente a largura total do elemento, facilitando a construção de layouts responsivos.
  • flex-shrink
    Funcionalidade: Define o fator de contração de um elemento dentro do Flexbox, ou seja, o quanto ele deve encolher face aos restantes.
    Por que foi usado: Utilizado (como 0) no <aside> da página temática para garantir que o menu lateral não seja esmagado pelo conteúdo principal quando a tela for pequena.
  • list-style-type
    Funcionalidade: Define o estilo do marcador utilizado numa lista não ordenada.
    Por que foi usado: Usado com o valor none para retirar as "bolinhas" padrão das listas do menu principal e da lista de definições, permitindo uma formatação de layout customizada.
  • line-height
    Funcionalidade: Define a distância vertical (altura) entre as linhas do texto.
    Por que foi usado: Utilizado (ex: 1.5) para afastar as linhas do texto longo, facilitando a leitura e melhorando a estética dos parágrafos.
  • cursor
    Funcionalidade: Altera o aspeto do cursor do mouse quando este passa sobre o elemento.
    Por que foi usado: Definido como pointer (mão de clique) em botões, links e no ícone do menu hambúrguer para dar um feedback visual de que o elemento é interativo.
  • user-select
    Funcionalidade: Controla se e como o texto de um elemento pode ser selecionado pelo utilizador.
    Por que foi usado: Configurado como none no ícone de texto do menu hambúrguer (☰) para evitar que este fique selecionado acidentalmente e manchado de azul durante o clique (especialmente em telemóveis).
