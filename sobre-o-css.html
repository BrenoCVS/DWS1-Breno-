Propriedades CSS utilizadas

  • Display: flex:

    A propriedade display: flex é utilizada para organizar os elementos dentro de um container de forma flexível. Por padrão, os elementos são posicionados lado a lado, facilitando a criação de menus e outras estruturas.

  • Justify-content: flex-start:

    A propriedade justify-content define como os elementos são distribuídos dentro de um container flexível. O valor flex-start faz com que os elementos sejam posicionados no início do container, no lado esquerdo.

  • Gap:

    A propriedade gap define o espaço entre os elementos de um container.
